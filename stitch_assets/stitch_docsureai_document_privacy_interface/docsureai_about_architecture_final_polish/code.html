About DocSureAI

DocSureAI is a computer-vision and OCR based document processing application that transforms document images into structured information while automatically detecting and visually redacting sensitive information.

CORE PIPELINE

Ten-Stage Processing Sequence

Stages 01 – 10
STAGE 01

Image Preprocessing

Grayscale conversion and bilateral filtering suppress noise while keeping document edges intact.

STAGE 02

Document Boundary Detection

Canny edge detection and contour approximation determine the outer quadrangle vertices of the page.

STAGE 03

Perspective Correction

Homography perspective rectification unwarps skewed document angles into a flat top-down surface.

STAGE 04

Image Enhancement

Adaptive histogram equalization (CLAHE) normalizes uneven scan lighting and boosts character contrast.

STAGE 05

Document Quality Assessment

Laplacian variance computes sharpness metrics to confirm readability before text parsing.

STAGE 06

Optical Character Recognition (OCR)

Deep neural text detection and character recognition transcribe localized glyphs into digital text.

STAGE 07

OCR Result Analysis

Confidence score thresholding and bounding box coordinate mapping filter recognition outputs.

STAGE 08

Document Structure Analysis

Spatial layout clustering reconstructs logical headings, key-value pairs, and tabular content.

STAGE 09

Sensitive Information Detection

Deterministic regular expression and structural pattern engines identify sensitive target fields.

STAGE 10

Visual Redaction

Solid opaque rectangle fills overwrite coordinate pixel arrays directly on the raster canvas.

DETECTION TARGETS

Supported Sensitive Information Types

Standard syntactic patterns identified and prepared for visual masking:

Email addresses Standard email address syntax across common domain structures
Phone numbers Standard regional, international, hyphenated, and parenthetical telephone formats
Aadhaar-like identifiers (12 digits) Continuous or space-delimited 12-digit identification patterns
Card-like sequences (16-digit payment card numbers) 16-digit segmented payment card numerical patterns
URLs & web links Uniform resource locators with standard http, https, or domain designations
